NotesMessaging is connections-only: a student can’t open a thread with someone whose request hasn’t been accepted (Market sellers included; see Market). Accepting a request unlocks Message and connection-only profile details; Decline removes it silently; Cancel withdraws a sent request; Remove ends the connection and closes the DM. New requests notify the recipient in-app and by email. The plus icon (mobile) and the New chat button (desktop) open the same pop-up: pick Direct message or Group chat, choose from accepted connections only, name the group if it’s a group. Sold and rating prompts appear in-thread. Club chats are moderated and muted by default. Filters (All, Market, Clubs) work in the inbox and in the floating Messages dock on every desktop screen. Tablet 768: list overlays the thread.
