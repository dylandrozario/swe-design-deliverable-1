# 09 Notifications & Settings — Mobile (390 × 800)

**Goal:** quiet by default. Digests over pings, granular control, quiet hours, easy privacy.
**Style:** LinkedIn-style alert list. See [style-guide.md](style-guide.md). On mobile, alerts open from the bell in the Home header.

## Screen 1 — Alerts
- **Header:** “Alerts” title · gold badge “Quiet 11p–8a” (moon icon).
- **Tabs:** All (on) · Events · Market · Clubs.
- **List** (avatar/icon, bold title, meta; unread rows have a hover-tint background + dot):
  - Ticket icon — “Acoustic Night starts at 7pm” — Event reminder · 2h ago — unread.
  - SK — “Sarah: ‘See you at O’Neill at 5’” — Market · 10m ago — unread.
  - RC — “Running Club weekly digest” — 3 updates · Yesterday.
  - Heart icon — “Price drop: Bike is now $80” — Saved item · 2d ago.

## Screen 2 — Settings
- **Header:** back · “Settings”.
- **Notifications** (label, then card of switch rows; each row = title + description + switch):
  - Event reminders — 2 hours before — on.
  - Club digest — Weekly summary — on.
  - Marketplace messages — Push for new inquiries — on.
  - Quiet hours — 11pm to 8am — on.
- **Privacy** (card of navigation rows, arrow at right): Dorm visible to — BC students only; Who can message me — Verified students.
- **`Report, block and safety`** (ghost, block, shield icon).
- **`Save changes`** (primary, block). Tap → toast “Preferences saved”. Failure → “Couldn’t save. Retry.”

## Behavior
- Switches respond immediately; Save commits.
- Defaults are low-noise: club announcements arrive as a digest.
